# Music Player App

A simple browser-based music player built with HTML, CSS, and JavaScript.
https://music-player-five-black.vercel.app/

## Features

- Play, pause, previous, and next controls
- Playlist of songs with metadata
- Dynamic display of the current song and artist
- Highlighted currently playing track
- Responsive web layout

## Files

- `index.html` - page structure
- `styles.css` - styling and layout
- `scripts.js` - player logic and playlist behavior

## How to run

1. Open the project folder.
2. Open `index.html` in your browser.
3. Use the controls to play music from the playlist.

## Notes

This project uses remote MP3 files from freeCodeCamp for the demo audio tracks.

## Browser support

Works in modern desktop browsers with JavaScript enabled.
